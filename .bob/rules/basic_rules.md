# Project Rules & Conventions

- **Static Only**: Keep this website completely static without adding build pipelines, npm packages, bundlers, or heavy external frameworks.
- **Styling**: Maintain all styles inside `css/styles.css` using the existing CSS custom properties (`--ink`, `--paper`, `--accent`, `--accent-soft`, `--muted`, `--line`).
- **Semantic HTML**: Use proper semantic HTML elements (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<nav>`) and ensure all pages remain accessible.
- **Consistency**: Keep the header navigation and footer markup aligned across `index.html`, `about.html`, and `contact.html`.
