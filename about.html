About this site

Why this repository exists and how it's put together.

This repository, rasidabdul.github.io, is a personal GitHub Pages site for Abdul Rasid. It contains no build step, no framework, and no external dependencies — just static HTML and CSS served directly from the main branch.

What's included

  • A responsive biography landing page (index.html)
  • Supporting content pages (about.html, contact.html)
  • A shared stylesheet (css/styles.css) with a mobile-first responsive layout
  • Baseline repository configuration (README.md, _config.yml, .gitignore)

Design goals

Keep it simple, keep it fast, and keep it easy to extend. Anyone can add a new page in minutes by copying the header/footer markup and linking it from the navigation bar.
